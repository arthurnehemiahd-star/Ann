## Vercel settings

When importing this folder into a new Vercel project:

- Framework Preset: Other
- Build Command: leave empty / disabled
- Output Directory: .
- Install Command: leave empty / disabled
- Root Directory: leave as the project root

There is no npm, React, or build process.
